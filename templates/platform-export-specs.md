# 平台輸出規格

工作室預設。各平台的長度、編碼與安全區會改，發布前對一下當前說明。這裡固定的是這個頻道的母帶，不是平台上限的完整清單。

## 母帶

先做一條直式母帶，再衍伸。不要為了三個平台各生成一次。

| 項目 | 預設 |
| --- | --- |
| 畫幅 | 9:16 |
| 像素 | 1080×1920 |
| 影格率 | 30 fps |
| 容器 | MP4 |
| 視訊 | H.264 |
| 聲音 | AAC，48 kHz，立體聲 |
| 封面 | 第 1 秒內能當靜幀的那一格，另外存一張 |

母帶與輸出檔放在專案的 `exports/`。該目錄被 git 忽略。

## 三個平台

| 平台 | 從母帶剪什麼 | 時長 | 另外的靜幀 |
| --- | --- | --- | --- |
| TikTok | 鉤子在第一秒。趨勢與日常 12–25 秒。方法論可 45–60 秒 | 見左 | 不需要，除非要做系列封面 |
| IG Reels | 同一條，方法論可留到 45–90 秒 | 見左 | 每週一則欄位靜幀：4:5（1080×1350）或直式 9:16 |
| X | 8–15 秒鉤子。工作日一則影片 | 見左 | 串文可加 1–2 張。16:9（1600×900）或 1:1 中心裁切 |

X 的 1:1 與 IG 的 4:5 從母帶裁切或用 Reframe。不要整支用新模型重抽。Reframe 會扣點，先看生成鍵。

## 發布節奏

以台北時間為準，細表在 `plan/monthly-usage-and-content-strategy.md` 的每週發布曆。

| 日子 | 主輸出 |
| --- | --- |
| 二 | 趨勢。TikTok 中午，IG 晚上，X 用鉤子版加一句英文 |
| 三 | 日常再創作，三平台同一條，X 另發前後對比靜幀 |
| 四 | 方法論完整集。X 是短鉤子加中文步驟串文 |
| 五 | 第二支趨勢 |
| 六 | 方法論切片或 4:5 靜幀 |
| 日 | 可重發本週最強鉤子。21:00 週報串文 |

## 檔名

```text
exports/YYYYMMDD-slug-master-9x16.mp4
exports/YYYYMMDD-slug-tiktok.mp4
exports/YYYYMMDD-slug-reels.mp4
exports/YYYYMMDD-slug-x.mp4
exports/YYYYMMDD-slug-cover-4x5.jpg
exports/YYYYMMDD-slug-x-16x9.jpg
```

`published.md` 只記連結與數據，不記檔案本體。
