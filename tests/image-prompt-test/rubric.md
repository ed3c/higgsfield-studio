# 評分規準（1–5）與通過線

每則提示詞 × 每個指定模型評一次，填入 `results.csv`。先看圖，再打分，不要先看其他模型的分數以免錨定。

五個維度等權。分母是 25。只評靜態圖；本測試不評影片、聲音或運鏡。

## 分數錨點（五個維度通用）

| 分 | 含義 |
| ---: | --- |
| 5 | 可直接進情緒板或當影片首幀，幾乎不用重跑 |
| 4 | 明顯可用，只有小瑕疵，不必換模型 |
| 3 | 方向對，但要修提示詞或再取一次才進得了製作 |
| 2 | 主題或畫幅對了一半，不能當這個鏡頭的母圖 |
| 1 | 跑題、壞構圖、錯字嚴重，或畫質不能用 |

提示詞要求出現卻完全沒有的元素，該維度打 1，不要留空。若提示詞要求不要文字，而畫面也沒有字，文字／產品項改評產品細節與是否守住「不要字」，不要因此打 1。若生成鍵顯示點數而沒有生成，不要打分，只填 `credits_shown` 與 `generated=no`。

## 1. 提示詞遵從　`score_adherence`

有沒有做到提示詞裡寫明的主體、場景、鏡頭、光線與限制。

- 5：所列主體、鏡頭焦段或視角、光線方向、時間與限制都在畫面上對得上。
- 4：核心主體與光線對，只有一項次要細節偏差（例如植物或霧的濃淡）。
- 3：主題對，但鏡頭或光線明顯不是所寫的那種（該微距卻是中景，該藍時卻是中午）。
- 2：只留下主題關鍵字，場景或動作跑掉。
- 1：幾乎是另一張圖。

## 2. 真實感／風格　`score_realism_style`

有沒有達到該則指定的風格，而且質感站得住。T03、T04、T12 走生活寫實或電影寫實；T05、T06 走時裝編輯與超現實；T10 走三種可辯認的美術材質；T01、T02、T11 走商業產品照。

- 5：材質、光、空氣感達到該類型的專業靜幀，沒有明顯 AI 破綻（多餘手指、熔掉的金屬、塑膠皮膚）。
- 4：風格對，只有局部破綻，不致於讓客戶在第一眼退出。
- 3：看得出想走哪種風格，但偏塑膠、偏髒，或超現實崩成奇幻海報。
- 2：風格錯置（UGC 看起來像香水廣告，產品照看起來像插畫）。
- 1：崩壞、嚴重偽影，或完全沒有風格控制。

## 3. 9:16 構圖　`score_composition_916`

是不是一張為直式社群拍的畫面，而不是 16:9 被硬裁。

- 5：主體落在直式舒適區，頭腳或產品上下有呼吸，可能的字幕區（下三分或 T02／T04／T11 的留白）是空的。
- 4：直式成立，只有輕微頂切或邊太滿。
- 3：能當 9:16 用，但主體置中死板，或左右像裁自橫圖。
- 2：明顯的橫圖思維，重要元素切在框外，或上下大片廢空間。
- 1：畫幅不對、變形到不能用，或主體被切掉。

## 4. 文字與產品保真　`score_text_product`

文字（若有要求）與虛構產品細節是否正確。沒有要求生成文字的題（T01、T05、T07、T08、T09、T10、T11、T12）改評：有沒有守住「不要字、不要商標」，以及產品或器物細節是否與提示詞相符。

- 5：該出現的字完全正確（T02 必須是繁體「霧嶼」、MISTISLE、COLD BREW OOLONG，一行不差）；不該出現的字沒有出現；產品顏色、材料、蓋型或反光條與簡報一致。
- 4：產品對，或文字接近可讀，只有很小的字距或筆畫問題，仍認得出品牌字。
- 3：產品大方向對，但文字有錯字、簡體、或多了提示詞沒寫的字；或杯子／瓶子細節含糊。
- 2：文字不可讀，或產品認不出是同一件設計。
- 1：亂字、假商標、或產品完全不對。T02 若寫成簡體「雾屿」或 MISTISLE 拼錯，最高 2。

T03 的時鐘不在這一格；T04 的時鐘必須可讀為 3:00，讀錯這項最高 2。

## 5. 一致性　`score_consistency`

分兩層，都打在這個分數裡，並在 `notes` 寫清楚。

1. **畫面內**：同一張裡的解剖、對稱、標籤左右、杯子或瓶子的結構不要自相矛盾（多餘肢體、兩個杯蓋、三格鶴變成三隻不同的鳥）。
2. **跨鏡**（有對再評，沒有對時不要為了空白而扣）：T01 與 T02 是同一支霧嶼瓶；T03 與 T04 是同一只圈圈杯；T05 與 T06 是同一人、同一件外套。先跑完一對再打這一層。T07–T12 只評畫面內，除非你自願用同一模型複跑第二張。

- 5：畫面內結構穩定；若有成對鏡頭，產品或造型立刻認得出是同一件。
- 4：小差異（霧的濃度、光線略變）但仍是同一設計。
- 3：同一主題，但瓶型、蓋色、外套紋路或人物臉型已經換了一版。
- 2：成對鏡頭幾乎不像同一專案，或單張裡出現結構矛盾。
- 1：嚴重自相矛盾（手指數錯、標籤左右不同、三格主題不一致）。

## 通過線

一筆「提示詞 × 模型」**通過**，須同時滿足：

- 五個分數都 ≥ 3
- 平均 ≥ 4.0（合計 ≥ 20）
- 若該則要求可讀文字（T02），或要求特定讀數（T04 的 3:00），則 `score_text_product` ≥ 4

一則提示詞**通過庫內測試**：四個必跑模型（Nano Banana Pro、Seedream 5.0 Pro、GPT Image 2.6、GPT Image 2.6 Flare）之中，至少一個通過。方案內含的可選對照不列入這條通過線。

一個必跑模型對某類用途**可進製作**：它在十二則裡的通過率 ≥ 80%（至少 10 則）。可選對照若通過，只註明「促銷結束後可當備案」，不佔這條標準。

未通過的題不要直接拿去跑影片。先改提示詞或換通過的必跑模型，再重測同一則，直到通過或寫下放棄原因。
