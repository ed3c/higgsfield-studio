# 在 higgsfield.ai 網站跑測試（不扣點）

這份指引只給網站手動操作，或按同樣步驟走的瀏覽器代理。不要用 Higgsfield MCP、官方 CLI，也不要在聊天室連線裡按生成：那些路徑會扣點，即使網站上同一個模型是免費的。

查價與促銷標示可能變動。**唯一準則是按下前看生成鍵。**

## 開始之前

1. 用 Neon 的 Ultra 帳戶登入 [higgsfield.ai](https://higgsfield.ai)。
2. 確認這次是圖像測試，不是影片製作。本包 12 則全部是靜態圖。
3. 打開 `prompts.md` 或手機上的測試 Page，另開 `results.csv` 準備填。
4. 在本機建立 `tests/image-prompt-test/outputs/` 用來存圖。圖不要提交進 git。
5. 知道 2K 無限次數的範圍：
   - 2026 年 11 月 20 日起 7 天、2K 無限次數（約至 11 月 27 日，以網站為準）：Nano Banana Pro、Seedream 5.0 Pro、GPT Image 2.6、GPT Image 2.6 Flare。
   - 方案內含、此測試視為免費：Nano Banana、Kling O1 Image、Seedream 4.5、Seedream 5.0 Lite、FLUX.2 Pro（2K）。
6. 不要訓練 Soul ID（官方頁面列為一次性 25 點）。不要開 Cinema Studio、Marketing Studio、Seedance、Kling 影片或任何 Video 頁籤。

## 每則、每個模型的步驟

1. 進入圖像生成頁面（Image、影像，或網站上同等的靜態圖工具）。若目前停在 Video 或 Cinema，先離開。
2. 選擇該則在 `prompts.md` 列出的第一個指定模型。名稱以網站為準，對一下本包寫的英文名。
3. 畫幅設為 **9:16**（直式）。解析度設為 **2K**。不要選 4K：這次無限次數寫的是 2K，4K 可能改扣點。
4. 看兩處標價，兩處都要免費才繼續：
   1. 模型名稱旁邊或模型列表裡，應出現 Unlimited、無限、免費、無限次數，或 0 點。
   2. **生成鍵**（Generate、生成，或同等按鈕）本身，應顯示 0、Unlimited、無限、免費，或無限符號，而且**不要出現點數數字**。
5. 若生成鍵、解析度切換或模型卡上出現任何點數（例如 `2`、`0.12`、`2 credits`、`2 點`），**立刻停止，不要按**。在 `results.csv` 該列填 `credits_shown`（照實抄標價）、`generated=no`，分數留空。然後檢查是不是誤選了 4K 或影片模式；改回 2K 圖像後再看一次。若仍顯示點數，改試同一則的下一個指定模型。
6. 兩處都確認免費後，把 `prompts.md` 裡該則的英文提示詞**整段原樣**貼進提示詞欄。第一輪不要加風格詞、不要加負面清單、不要上傳參考圖。本包要測的是提示詞原文。
7. 再看一次生成鍵。標價沒變，才按下生成。
8. 等圖出來，下載到 `outputs/`，檔名：`T01-nano-banana-pro-01.png`（測試 id、模型短名、取次）。同一則同一模型若重跑，取次加一。
9. 用 `rubric.md` 打五個分數，填 `results.csv`。`date` 用台北時間的日期（Asia/Taipei），例如 `2026-11-21`。
10. 同一則的下一個指定模型重複步驟 2–9，趁印象還在時對照。一則的指定模型都跑完，再換下一則。
11. 成對鏡頭（T01–T02、T03–T04、T05–T06）跑完後，補打跨鏡一致性，並寫在 `notes`。

## 生成鍵看起來可能是這樣

網站改版時用字會變，以下是判斷方式，不是保證會看到的原文：

- **可以按**：生成鍵是「Generate」「生成」，旁邊是 `Unlimited`、`無限`、`免費`、`0`、`0 credits`，或無限符號，沒有其他數字。
- **不可以按**：生成鍵或旁邊出現點數數字、點數圖示加數量，或「使用 N 點」「N credits」。即使你記得這個模型應該免費，也以當下標價為準。
- **不確定**：鍵上什麼都沒寫。不要猜。改切一次 2K 與 9:16，或換一個列為免費的模型，直到標價出現。還是空白就停止該次，把情況寫進 `notes`。

## 不要做的事

- 不要用這個聊天室、MCP 或 CLI 生成。README 已寫：網站上的 Unlimited 不會跟著那些路徑走。
- 不要生成影片，不要把通過的靜幀立刻拿去 image-to-video。那是測試通過、並且 Neon 核准預算之後的事。
- 不要選 4K「先看看」。
- 不要一次開很多批次，以免某次誤切到扣點模式。
- 不要把輸出圖提交進 git。只提交填好的 `results.csv` 與筆記。

## 做完之後

1. 數通過的「提示詞 × 模型」（見 `rubric.md` 的通過線）。
2. 記下哪些模型適合產品字（通常看 T02、T04、T11）、哪些適合人物與 UGC（T03、T07）、哪些適合超現實時裝（T05、T06）。
3. 未通過的提示詞先改寫再測同一則，不要直接當生產環境的定稿模板。
4. 十二則裡，作品集六則（T01–T06）與六個領域範本（T07–T12）都至少有一個模型通過，才建議進入影片或正式生產。
