# 在 higgsfield.ai 網站跑測試（不扣點）

這份指引只給網站手動操作，或按同樣步驟走的瀏覽器代理。不要用 Higgsfield MCP、官方 CLI，也不要在聊天室連線裡按生成：那些路徑會扣點，即使網站上同一個模型是免費的。

查價與促銷標示可能變動。**唯一準則是按下前看生成鍵。**

## 跑的順序（先用快到期的無限次數）

7 天 2K 無限次數從 2026 年 11 月 20 日起，約至 11 月 27 日，以網站標示為準。這四個模型要先跑完，再碰方案內含的對照模型。

**第一輪（必跑，先做完）：** 對 T01 到 T12，每一則依此順序跑四次，再換下一則：

1. Nano Banana Pro
2. Seedream 5.0 Pro
3. GPT Image 2.6
4. GPT Image 2.6 Flare

同一則的四張趁印象還在時對照打分。成對鏡頭（T01–T02、T03–T04、T05–T06）兩則的必跑都完成後，再補跨鏡一致性。

若 7 天期限將到、第一輪還沒跑完：暫停打分也沒關係，先把剩下的必跑生成做完。不要為了可選對照而佔用這段無限次數。

**第二輪（可選，第一輪全部完成後才開始）：** 每則只多跑一個方案內含模型，見 `prompts.md` 的可選對照表。用來檢查促銷結束後，Nano Banana、Kling O1 Image、Seedream 4.5、Seedream 5.0 Lite、FLUX.2 Pro（2K）還有沒有堪用的備案。第二輪不是通過線的一部分。

## 開始之前

1. 用 Neon 的 Ultra 帳戶登入 [higgsfield.ai](https://higgsfield.ai)。
2. 確認這次是圖像測試，不是影片製作。本包 12 則全部是靜態圖。
3. 打開 `prompts.md` 或手機上的測試 Page，另開 `results.csv` 準備填。先填 `priority=primary` 的列。
4. 在本機建立 `tests/image-prompt-test/outputs/` 用來存圖。圖不要提交進 git。
5. 不要訓練 Soul ID（官方頁面列為一次性 25 點）。不要開 Cinema Studio、Marketing Studio、Seedance、Kling 影片或任何 Video 頁籤。

## 每一次生成的步驟

1. 進入圖像生成頁面（Image、影像，或網站上同等的靜態圖工具）。若目前停在 Video 或 Cinema，先離開。
2. 選擇這一輪指定的模型。第一輪只選上面四個 7 天無限次數模型，名稱以網站為準。
3. 畫幅設為 **9:16**（直式）。解析度設為 **2K**。不要選 4K：這次無限次數寫的是 2K，4K 可能改扣點。
4. 看兩處標價，兩處都要免費才繼續：
   1. 模型名稱旁邊或模型列表裡，應出現 Unlimited、無限、免費、無限次數，或 0 點。
   2. **生成鍵**（Generate、生成，或同等按鈕）本身，應顯示 0、Unlimited、無限、免費，或無限符號，而且**不要出現點數數字**。
5. 若生成鍵、解析度切換或模型卡上出現任何點數（例如 `2`、`0.12`、`2 credits`、`2 點`），**立刻停止，不要按**。在 `results.csv` 該列填 `credits_shown`（照實抄標價）、`generated=no`，分數留空。然後檢查是不是誤選了 4K 或影片模式；改回 2K 圖像後再看一次。若仍顯示點數，改試同一則第一輪的下一個模型。
6. 兩處都確認免費後，把 `prompts.md` 裡該則的英文提示詞**整段原樣**貼進提示詞欄。第一輪不要加風格詞、不要加負面清單、不要上傳參考圖。本包要測的是提示詞原文。
7. 再看一次生成鍵。標價沒變，才按下生成。
8. 等圖出來，下載到 `outputs/`，檔名：`T01-nano-banana-pro-01.png`（測試 id、模型短名、取次）。同一則同一模型若重跑，取次加一。
9. 用 `rubric.md` 打五個分數，填 `results.csv`。`date` 用台北時間的日期（Asia/Taipei），例如 `2026-11-21`。`priority` 已預填：第一輪是 `primary`，第二輪是 `optional`。
10. 同一則第一輪的下一個模型重複步驟 2–9。四個必跑都跑完，再換下一則。十二則的第一輪都完成後，才進入可選對照。

## 生成鍵看起來可能是這樣

網站改版時用字會變，以下是判斷方式，不是保證會看到的原文：

- **可以按**：生成鍵是「Generate」「生成」，旁邊是 `Unlimited`、`無限`、`免費`、`0`、`0 credits`，或無限符號，沒有其他數字。
- **不可以按**：生成鍵或旁邊出現點數數字、點數圖示加數量，或「使用 N 點」「N credits」。即使你記得這個模型應該免費，也以當下標價為準。
- **不確定**：鍵上什麼都沒寫。不要猜。改切一次 2K 與 9:16，或換一個列為免費的模型，直到標價出現。還是空白就停止該次，把情況寫進 `notes`。

## 不要做的事

- 不要用這個聊天室、MCP 或 CLI 生成。README 已寫：網站上的 Unlimited 不會跟著那些路徑走。
- 不要生成影片，不要把通過的靜幀立刻拿去 image-to-video。那是測試通過、並且 Neon 核准預算之後的事。
- 不要選 4K「先看看」。
- 不要在第一輪還沒跑完時，改去跑 FLUX.2 Pro、Kling O1 Image、Seedream 4.5、Seedream 5.0 Lite 或 Nano Banana。
- 不要一次開很多批次，以免某次誤切到扣點模式。
- 不要把輸出圖提交進 git。只提交填好的 `results.csv` 與筆記。

## 做完之後

1. 只數第一輪（`priority=primary`）通過的「提示詞 × 模型」（見 `rubric.md` 的通過線）。可選對照另外記，不列入通過線。
2. 記下這四個 7 天模型各自適合什麼：產品字（T02、T04、T11）、人物與 UGC（T03、T07）、超現實時裝（T05、T06）。
3. 未通過的提示詞先改寫，再只用第一輪的四個模型重測同一則，不要直接當生產環境的定稿模板。
4. 十二則裡，作品集六則（T01–T06）與六個領域範本（T07–T12）都至少有一個必跑模型通過，才建議進入影片或正式生產。
