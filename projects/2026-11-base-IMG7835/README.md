## 原片聲音

- 一軌 AAC 48 kHz 立體聲（另外幾條是 iPhone 的空間音訊與 metadata 軌）。
- 從頭到尾是連續的環境聲：平均 -30.8 dBFS、峰值 -16 dBFS，每 5 秒的平均音量都在 -29 到 -34 dB 之間，沒有任何靜音段。
- 能量集中在 100–1,200 Hz，高頻很少，偶爾有小的瞬間聲（腳步之類），像展廳空調加遠處人聲。頻譜上看不出清楚的對白，但沒有實際聽過、也沒有做語音辨識。
- 結論：不能當成品聲音。比賽規定音樂與人聲都要 AI 生成；作品集版也只適合當剪輯時對節奏用的暫時底噪。

## 風險

- **地上水紋閃動**：Genjutsu 可能把光斑當成動作，畫面會「沸騰」。關鍵幀和提示詞都把地面寫死（濕石、泥水、花窗影），不行就先遮罩地面，只拿人物動作。
- **00:41 暗場**：D1、D5 把它當劇情用；其他方向剪掉 00:40.5–00:43，或把那段當成刻意的停電。
- **反光襯衫**：金屬灰襯衫隨光變色，模型容易畫成盔甲或塑膠。虛構角色一律寫「matte grey work jacket」；D4 要保留本人時再接受反光。
- **臉的辨識度**：臉只有約 70 像素，直接拿來訓練 Soul ID 不夠，要另外補拍正面近景。Flare 重繪特寫時也可能跑掉。
- **比賽規則**：不得出現可辨識真人，包括自己；所有影像都要在 Contest Project、創作期內生成。原片本身不能直接出現在比賽片裡。拿真人影片當 Genjutsu 動作參考是否允許，規則沒寫清楚，要先確認。
- **裝置作品版權**：原片裡的水箱是別人的作品。五個方向都把它換掉，原片畫面不直接公開。
